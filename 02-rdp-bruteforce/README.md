# RDP Brute Force Detection Lab

## Objective
Simulate and investigate an RDP brute force attack against a Windows Server environment.

## Tools Used
- Crowbar
- xfreerdp
- Wireshark
- Security Onion
- Zeek
- Suricata
- Splunk
- Kali Linux
- Windows Server 2019

## Skills Demonstrated
- Threat Detection
- Brute Force Analysis
- Windows Event Log Investigation
- SIEM Correlation
- IDS Analysis
- Incident Investigation
