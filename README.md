## Projects

### 1. Nmap Reconnaissance & Detection Lab
Simulated adversary reconnaissance using Nmap against a Windows Domain Controller with detection through Wireshark, Security Onion, Zeek, Suricata, and Splunk.

### 2. RDP Brute Force Detection Lab
Performed RDP brute force activity from Kali Linux and investigated authentication failures, successful compromise events, and network telemetry across multiple SOC tools.

### 3. SMB Brute Force Detection & Telemetry Analysis
Conducted SMB brute force attacks against Active Directory services and correlated packet captures, Zeek NTLM logs, Windows Event IDs 4624/4625, and Splunk dashboards.
